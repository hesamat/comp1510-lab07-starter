# COMP 1510 Lab 07 - Transit Stop Finder

Follow the lab handout (PDF) for the full requirements.

`transit.py` is the program you complete. `NETWORK` at the top of the
file holds the transit routes, and you do not change it. Write the
whole suite in `tests/test_lab07.py` yourself: there are no starter
examples this time, and you test every function before you implement
it.

`main()` starts with one line that prints the header. Leave it alone.
You add your own lines in the pricing part.

Submit `transit.py` and `test_lab07.py` to the Lab 7 dropbox in
Learning Hub before the deadline.
